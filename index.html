    如何加上自己的 Pine 指標與買賣訊號

    TradingView 免費 Widget 無法在站內「現場寫」Pine，但你可以把自己在 TradingView 寫好的 Pine 指標發佈後加到圖上，效果完全一樣。

    1. 到 TradingView 寫指標
      開啟 TradingView Pine Editor，撰寫你的買賣訊號指標。例如用 plotshape() 在條件成立時畫出買點／賣點。 
      // 範例：雙均線金叉買、死叉賣
//@version=5
indicator("My Buy/Sell Signal", overlay=true)
fast = ta.sma(close, 5)
slow = ta.sma(close, 20)
buy  = ta.crossover(fast, slow)
sell = ta.crossunder(fast, slow)
plotshape(buy,  style=shape.triangleup,   color=color.green, location=location.belowbar, size=size.small)
plotshape(sell, style=shape.triangledown, color=color.red,   location=location.abovebar, size=size.small)
    2. 發佈指標（可設私密）
      在 Pine Editor 按 Publish，標題打清楚。可在「Visibility」設為 Private，只有你自己看得到。
    3. 在下方圖表加入
      關閉此視窗後，點圖表工具列的 fx（指標）鈕 → 搜尋你剛發佈的指標標題 → 點擊加入。買賣訊號就會出現在圖上。
    4. 讓網站預設自動帶入你的指標
      到下方程式碼裡的 defaultStudies 陣列，加入你的指標腳本 ID（在 TradingView 指標頁 URL 中可找到，形如 STD;My%20Buy%2FSell%20Signal）。存檔重整即預設載入。

    註：若要完全在站內寫／回測 Pine 並接自己的資料源，需改用 TradingView Charting Library（需向 TradingView 申請免費非商業授權 + 自架資料後端）。對個人小站通常沒必要。
